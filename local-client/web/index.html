在 GitHub 的 webhook 设置里勾上「Workflow runs」事件，下次跑 CI 就会出现在这里。

这里的范围：webhook 的 workflow_run 载荷只有运行级别的信息—— 工作流名、分支、状态、结论、用时、提交。点开一行能看到这些细节和「在 GitHub 上打开」。
单个运行里的 job、每个步骤和日志不在 webhook 载荷里， 要调 GitHub REST API（/actions/runs/{id}/jobs、/logs）才拿得到： 公开仓库可以匿名读（每小时 60 次），私有仓库需要 PAT。
